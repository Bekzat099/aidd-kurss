# Prompt log — 2-сабақ

AI-Driven Development · 1-апта · 2-сабақ. Әр маңызды әрекет: режим, промпт, нәтиже, тексеру.

## Ережелер (сабақтан)

1. `<…>` орнына өз жобамның мәнін қойдым; мағынасын түсінбеген промптты жібермедім
2. Құпия, пароль, токен, `.env` мазмұны, жеке дерек — промптқа түспеді
3. Алдымен жоспар (Planning) → бекіту → бір қадам
4. Агент ұсынған команданы оқып барып рұқсат бердім
5. Нәтижені іске қосып тексердім
6. Түсіндіре алмаған код есептелмейді

## 2026-11-06

### 1 · Ортаны тексеру (PLANNING) — П1

**Промпт:** Терминалда ортамды тексер: `python --version`, `git --version`, `docker --version`. Әр команданы іске қоспас бұрын көрсетіп, рұқсат сұра. Нәтижені кесте етіп бер: құрал · нұсқа · курсқа жеткілікті ме (Python ≥ 3.12). Ештеңе орнатпа.

| Құрал | Нұсқа | Жеткілікті ме |
|---|---|---|
| Python | 3.13.2 | ✅ (≥ 3.12) |
| Git | 2.56.0.windows.4 | ✅ |
| GitHub CLI (gh) | 2.102.0 | ✅ |

**Тексеру:** агент рұқсатсыз команда іске қосқан жоқ; кестеде құралдар бар. Docker 6-аптаға дейін тек орнатылған болуы керек.

### 2 · hello.py (FAST)

**Промпт:** `hello.py` скриптінің жоспары: атымды сұрап, «Сәлем, <аты>! Бүгін <күн.ай.жыл>» деп шығарсын. Тек стандартты кітапхана (`datetime`). Алдымен жоспарды көрсет, команданы рұқсат бергенде ғана іске қос.

**Кодта маңыздысы:** `datetime.date.today()` — бүгінгі күн; `input(...).strip()` — енгізілген атты тазалайды; бос ат болса — «Достым».

**Тексеру:**

```text
Атыңызды жазыңыз: Әли
Сәлем, Әли! Бүгін 6.11.2026
```

> Ескертпе: Windows-та терминал кодты cp1251-де ұстаса, қазақ әріптері (ң, қ, ә) үзіледі — алдымен `chcp 65001` немесе UTF-8 терминал (Windows Terminal) қолдану керек.

### 3 · .gitignore + README (FAST) — П2

**Промпт:** Python жобасы үшін `.gitignore` жаса. Міндетті: `.env`, `.venv/`, `__pycache__/`, `node_modules/`, `*.log`. README.md: жоба атауы, мақсаты (1 сөйлем), «Қалай іске қосу керек». Әр жолға бір сөйлемдік түсіндірме. `git commit`-ті өзің жасама.

**Тексеру:** `.env` шынымен `.gitignore`-да; `git status`-та `.venv/` көрінбейді.

### 4 · Коммит хабарламасы (FAST) — П3

**Промпт:** `git diff --staged` нәтижесін оқы да, Conventional Commits форматында бір коммит хабарламасын ұсын, 72 таңбадан аспасын. Құпия көрінсе — коммитті тоқтатып, айта бер. Коммитті өзің жасама.
